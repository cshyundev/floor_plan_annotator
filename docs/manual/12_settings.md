# 12. 환경설정 및 단축키

환경설정(Preferences)에서 자동저장 간격 등 프로그램 동작을 조정할 수 있습니다. 이 챕터에서는 모든 단축키 목록도 함께 제공합니다.

---

## 12.1 Preferences 창 열기

`Tools > Preferences...` 선택

![Preferences 창 전체 — Auto-save, Startup 섹션](images/12_preferences_dialog.png)

---

## 12.2 자동저장 설정 (Auto-save)

| 설정 | 설명 | 기본값 |
|------|------|--------|
| **Enable auto-save** | 자동저장 기능 활성화 | 활성화 |
| **Interval (minutes)** | 자동저장 간격 | 5분 |

![Auto-save 설정 항목 — 체크박스와 간격 입력 필드](images/12_autosave_settings.png)

설정 변경 후 **OK**를 클릭하면 즉시 적용됩니다.

> **자세한 내용**: [10. 파일 관리](10_file_management.md)의 자동저장 섹션을 참고하세요.

---

## 12.3 시작 옵션 (Startup)

| 설정 | 설명 |
|------|------|
| **Load sample data on startup** | 프로그램 시작 시 샘플 데이터 자동 로드 |

샘플 데이터가 포함된 경우에만 활성화할 수 있습니다.

---

## 12.4 전체 단축키 목록

### 도구 전환

| 단축키 | 도구 | 설명 |
|--------|------|------|
| `ESC` | 선택 (Select) | 어노테이션 선택/이동 모드 |
| `W` | 벽 (Wall) | 직선 벽 그리기 |
| `R` | 방 (Room) | 방 다각형 그리기 |
| `Z` | 구역 (Zone) | 구역 다각형 그리기 |
| `O` | 객체 (Object) | OBB 객체 그리기 |

### 파일 작업

| 단축키 | 동작 |
|--------|------|
| `Ctrl+S` | 현재 파일 저장 |
| `Ctrl+Shift+S` | 다른 이름으로 저장 |

### 편집 작업

| 단축키 | 동작 |
|--------|------|
| `Ctrl+Z` | 실행 취소 (Undo) |
| `Ctrl+Y` | 다시 실행 (Redo) |
| `Ctrl+C` | 선택한 항목 복사 |
| `Ctrl+V` | 붙여넣기 |
| `Delete` | 선택한 항목 삭제 |
| `Backspace` | 선택한 항목 삭제 (Delete와 동일) |

### 뷰 작업

| 단축키 | 동작 |
|--------|------|
| `F` | 전체 화면에 맞추기 (뷰 리셋) |
| 마우스 휠 | 줌인/줌아웃 |

### 그리기 중 조작

| 단축키/조작 | 동작 |
|------------|------|
| `Shift` (누르는 동안) | 스냅 일시 토글 |
| 우클릭 | 그리기 종료 (벽/방/구역 도구) |
| `ESC` | 그리기 취소 및 선택 도구로 전환 |

### 객체 선택 후 조작

| 단축키/조작 | 동작 |
|------------|------|
| `Ctrl` + 마우스 휠 | 3D Height 조절 |
| `Ctrl+Shift` + 마우스 휠 | Elevation 조절 |

## 12.5 우클릭 컨텍스트 메뉴 정리

### 벽 세그먼트 우클릭

| 항목 | 동작 |
|------|------|
| Align Horizontal | 수평으로 정렬 |
| Align Vertical | 수직으로 정렬 |

### 노드(꼭짓점) 우클릭 (2개 세그먼트 연결 시)

| 항목 | 동작 |
|------|------|
| Make Perpendicular | 두 세그먼트를 90°로 정렬 |

### 방/구역 우클릭

| 항목 | 동작 |
|------|------|
| [타입 목록] | 타입 변경 (현재 타입에 체크 표시) |

### 객체 우클릭

| 항목 | 동작 |
|------|------|
| [타입 목록] | 타입 변경 (현재 타입에 체크 표시) |

## 12.6 고급 설정 (config 파일)

다음 파일들을 직접 편집하여 더 세밀한 설정이 가능합니다. 변경 후 프로그램 재시작이 필요합니다.

| 파일 | 설명 |
|------|------|
| `config/ui_config.yaml` | 줌 범위, 노드 크기, 스냅 각도, 자동저장 기본값 등 |
| `config/colors.yaml` | 시스템 색상 (스냅 가이드, 노드, 벽 기본 색상 등) |
| `config/shortcuts.yaml` | 단축키 재지정 |
| `config/rooms.yaml` | 방 타입 정의 |
| `config/custom_polygons.yaml` | 구역 타입 정의 |
| `config/objects.yaml` | 객체 타입 정의 |

> **주의**: 설정 파일을 잘못 편집하면 프로그램이 정상적으로 동작하지 않을 수 있습니다. 편집 전에 백업을 권장합니다.
