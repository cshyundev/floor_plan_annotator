# 1. 인터페이스 개요

이 챕터에서는 Floor Plan Annotator의 전체 화면 구성과 각 영역의 역할을 설명합니다.

---

## 1.1 프로그램 실행

터미널에서 프로젝트 루트 디렉토리로 이동한 후 다음 명령어를 실행합니다.

```bash
python3 -m src.main
```

---

## 1.2 전체 UI 구성

프로그램을 실행하면 다음과 같은 화면이 나타납니다.

![전체 UI 레이아웃 — 좌측 3D 뷰어, 우측 2D 캔버스, 상단 메뉴바 및 도구 모음, 우측 도크 패널](images/01_ui_overview.png)

화면은 크게 네 영역으로 구성됩니다.

| 영역 | 위치 | 역할 |
|------|------|------|
| **메뉴바** | 최상단 | 파일 관리, 도구 설정 메뉴 |
| **도구 모음** | 메뉴바 아래 | 어노테이션 도구 선택 버튼 |
| **3D 뷰어** | 좌측 | 3D 포인트 클라우드/메시 표시 및 높이 슬라이싱 |
| **2D 캔버스** | 우측 (중앙) | 평면도 어노테이션 작업 영역 |
| **도크 패널** | 우측 끝 | 어노테이션 속성 및 뷰 컨트롤 |

---

## 1.3 메뉴바

### File 메뉴

![File 메뉴 펼쳐진 상태](images/01_menu_file.png)

| 항목 | 단축키 | 설명 |
|------|--------|------|
| Load Point Cloud | — | PLY, PCD, OBJ, STL 형식의 포인트 클라우드 로드 |
| Load Occupancy Grid | — | ROS2 맵 서버 형식(YAML + PGM/PNG) 로드 |
| Recent Files | — | 최근에 열었던 파일 목록 (최대 5개) |
| Save Project | `Ctrl+S` | 현재 프로젝트 저장 |
| Save Project As | `Ctrl+Shift+S` | 다른 위치/이름으로 저장 |
| Exit | — | 프로그램 종료 (저장 여부 확인) |

### Tools 메뉴

![Tools 메뉴 펼쳐진 상태](images/01_menu_tools.png)

| 항목 | 설명 |
|------|------|
| Manage Types... | 방/구역/객체 타입의 색상 및 이름 편집 |
| Preferences... | 자동저장, 시작 옵션 등 환경설정 |

---

## 1.4 도구 모음

상단의 도구 모음에서 현재 사용할 어노테이션 도구를 선택합니다. 키보드 단축키로도 즉시 전환할 수 있습니다.

![도구 모음 — 5가지 도구 버튼](images/01_toolbar.png)

| 도구 | 단축키 | 아이콘 설명 |
|------|--------|------------|
| 선택 (Select) | `ESC` | 어노테이션 선택 및 이동 |
| 벽 (Wall) | `W` | 직선 벽 그리기 |
| 방 (Room) | `R` | 방 다각형 그리기 |
| 구역 (Zone) | `Z` | 사용자 정의 구역 그리기 |
| 객체 (Object) | `O` | OBB 객체 그리기 |

현재 활성화된 도구는 버튼이 강조 표시됩니다.

---

## 1.5 2D 캔버스

2D 캔버스는 평면도를 보고 어노테이션을 그리는 주 작업 영역입니다.

![2D 캔버스 — 배경 이미지와 어노테이션이 표시된 상태](images/01_canvas_2d.png)

### 캔버스 탐색

| 조작 | 동작 |
|------|------|
| 마우스 휠 | 줌인/줌아웃 |
| 좌클릭 + 드래그 (빈 공간) | 캔버스 패닝 (이동) |
| `F` 키 | 전체 화면에 맞추기 (뷰 리셋) |

### 좌표 표시

캔버스에는 원점(0, 0)을 기준으로 X축(빨간색), Y축(초록색)이 표시됩니다. 모든 좌표는 미터(m) 단위입니다.

---

## 1.6 3D 뷰어

좌측의 3D 뷰어에서는 로드한 3D 데이터와 어노테이션이 3D로 표시됩니다.

![3D 뷰어 — 포인트 클라우드와 벽/방 어노테이션이 3D로 표시된 상태](images/01_viewer_3d.png)

| 조작 | 동작 |
|------|------|
| 우클릭 + 드래그 | 3D 뷰 회전 |
| 중간 클릭 + 드래그 | 3D 뷰 패닝 |
| 마우스 휠 | 줌인/줌아웃 |

3D 뷰어 아래의 **Z 슬라이더**를 조작하면 특정 높이의 단면을 2D 캔버스 배경으로 표시할 수 있습니다.

---

## 1.7 타이틀바 상태 표시

저장되지 않은 변경사항이 있을 때 타이틀바에 `*` 가 표시됩니다.

```
Floor Plan Annotator — annotations.json *
```

`Ctrl+S`로 저장하면 `*`가 사라집니다.
