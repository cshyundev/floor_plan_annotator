# 11. 3D 뷰어

3D 뷰어는 로드한 3D 데이터를 시각화하고, 2D 어노테이션을 3D로 확인할 수 있는 영역입니다. 2D 캔버스에 그린 어노테이션은 자동으로 3D 뷰어에 동기화됩니다.

---

화면 좌측에 3D 뷰어가 위치합니다.

## 11.2 마우스 조작

| 조작 | 동작 |
|------|------|
| **우클릭 + 드래그** | 3D 뷰 회전 |
| **중간 클릭(휠 클릭) + 드래그** | 3D 뷰 패닝 |
| **마우스 휠** | 줌인/줌아웃 |

---

## 11.3 높이 슬라이싱 (Z 슬라이더)

3D 뷰어 아래의 **Z 슬라이더**로 표시할 높이를 조절합니다.

![Z 슬라이더와 표시 모드 드롭다운 — 3D 뷰어 하단 컨트롤](images/11_z_slider_controls.png)

| 컨트롤 | 설명 |
|--------|------|
| **Z 슬라이더** | 슬라이스 높이 조절 (3D 뷰어에 수평 평면으로 표시) |
| **Slice** 모드 | 현재 Z 높이 근방의 포인트만 2D 캔버스 배경으로 표시 |
| **All Points** 모드 | 전체 포인트를 위에서 내려다본 형태로 2D 캔버스 배경에 표시 |

슬라이더를 조절하면 2D 캔버스의 배경 이미지가 실시간으로 업데이트됩니다.

---

## 11.4 2D 어노테이션의 3D 동기화

2D 캔버스에서 어노테이션을 추가하면 즉시 3D 뷰어에도 반영됩니다.

![3D 동기화 — 벽, 방, 객체가 3D로 표시된 상태](images/11_annotation_3d_sync.png)

### 타입별 3D 표현

| 어노테이션 | 3D 표현 |
|-----------|---------|
| **벽 (Wall)** | 높이 1.5m의 수직 평면 |
| **방 (Room)** | 바닥 다각형 (바닥 평면에 투영) |
| **구역 (Zone)** | 바닥 다각형 (바닥 평면에 투영) |
| **객체 (Object)** | OBB 와이어프레임 박스 (elevation + 3D height) |

---

## 11.5 객체 3D 속성

객체 어노테이션에는 3D 공간에서의 높이 정보가 포함됩니다.

### 속성 설명

| 속성 | 설명 |
|------|------|
| **Elevation** | 바닥에서 객체 바닥면까지의 높이 (m). 예: 테이블 위의 물건은 0.75m |
| **3D Height** | 객체 자체의 높이 (m). 예: 의자 높이 0.45m |

### 속성 조절 방법

객체를 선택한 상태에서 마우스 휠을 이용합니다.

| 조작 | 동작 |
|------|------|
| `Ctrl` + 마우스 휠 위 | 3D Height 증가 |
| `Ctrl` + 마우스 휠 아래 | 3D Height 감소 |
| `Ctrl+Shift` + 마우스 휠 위 | Elevation 증가 |
| `Ctrl+Shift` + 마우스 휠 아래 | Elevation 감소 |

![객체 3D Height 조절 — 3D 뷰어에서 박스 높이 변화](images/11_object_3d_height.png)

### 타입별 기본값

각 객체 타입에는 기본 Elevation과 3D Height가 지정되어 있습니다. 새 객체를 생성하면 타입의 기본값이 자동으로 적용됩니다. 기본값은 [9. 타입 관리](09_type_manager.md)에서 편집할 수 있습니다.

---

## 11.6 좌표계와 3D 뷰어

좌표계 설정에 따라 3D 데이터와 어노테이션이 올바르게 정렬됩니다.

- **ROS**: Z축이 위쪽 방향
- **OpenCV**: Y축이 아래쪽
- **OpenGL**: Y축이 위쪽

좌표계가 맞지 않으면 2D 어노테이션과 3D 데이터의 위치가 어긋날 수 있습니다. 데이터 로드 시 올바른 좌표계를 선택하세요.

> **자세한 내용**: [2.5 좌표계 선택](02_loading_data.md#25-좌표계-선택)을 참고하세요.

---

## 11.7 3D 뷰어가 비활성화된 경우

Open3D 라이브러리가 설치되지 않은 환경에서는 3D 뷰어가 비활성화된 상태로 표시됩니다. 이 경우에도 2D 캔버스의 어노테이션 기능은 정상적으로 사용할 수 있습니다.
