# 7. 선택 및 편집

선택 도구는 기존 어노테이션을 선택하고 이동, 삭제, 복사하는 데 사용합니다. 그리기 도구를 사용하다가 편집이 필요할 때 언제든지 `ESC`로 전환할 수 있습니다.

---

## 7.1 선택 도구 활성화

- 키보드: `ESC`
- 도구 모음에서 선택 아이콘 클릭

---

## 7.2 단일 항목 선택

어노테이션 위에서 클릭하면 해당 항목이 선택됩니다.

- **벽 세그먼트**: 선 위를 클릭
- **방/구역**: 다각형 내부를 클릭
- **객체**: 직사각형 영역 내부를 클릭

선택된 항목은 테두리와 핸들이 강조 표시됩니다.

![단일 선택 — 선택된 방이 강조 표시된 상태](images/07_single_select.png)

### 겹쳐 있는 항목 순환 선택

같은 위치에 여러 어노테이션이 겹쳐 있을 때 같은 위치를 반복 클릭하면 아래 항목들이 순서대로 순환하며 선택됩니다.

---

## 7.3 다중 선택 (루버밴드)

캔버스의 빈 공간에서 클릭+드래그하면 고무줄(루버밴드) 선택 영역이 표시됩니다.

![루버밴드 다중 선택 — 드래그 영역 내 모든 항목 선택](images/07_rubberband_select.png)

드래그 영역 내에 포함된 모든 어노테이션이 선택됩니다.

---

## 7.4 이동

선택 도구로 어노테이션을 드래그하면 이동합니다.

| 어노테이션 | 드래그 위치 | 동작 |
|-----------|------------|------|
| 벽 세그먼트 | 노드(끝점) | 해당 노드만 이동 |
| 방/구역 | 다각형 내부 | 전체 이동 |
| 방/구역 | 꼭짓점(노드) | 해당 꼭짓점만 이동 |
| 객체 | 중심 영역 | 전체 이동 |
| 객체 | 모서리 핸들 | 크기 조절 |
| 객체 | 회전 핸들 | 회전 |

---

## 7.5 삭제

선택한 어노테이션을 삭제합니다.

- 키보드: `Delete` 또는 `Backspace`

다중 선택 후 삭제하면 선택된 모든 항목이 삭제됩니다.

> **주의**: 삭제는 실수로 취소하려면 `Ctrl+Z`(Undo)를 사용하세요.

---

## 7.6 복사 및 붙여넣기

방, 구역, 객체를 복사하여 같은 형태를 빠르게 여러 개 생성할 수 있습니다.

> **참고**: 벽(Wall) 세그먼트는 복사/붙여넣기가 지원되지 않습니다.

### 복사

선택 후 `Ctrl+C`

### 붙여넣기

`Ctrl+V`

붙여넣어진 항목은 원본에서 약간 오프셋된 위치에 생성됩니다. 새로운 ID가 자동으로 부여됩니다.

![복사 후 붙여넣기 — 오프셋 위치에 새 객체 생성](images/07_copy_paste.png)

### 붙여넣기 동작

| 항목 | 동작 |
|------|------|
| **방/구역** | 새 꼭짓점 생성 (기존 어노테이션과 노드 공유 안 함) |
| **객체** | 동일한 크기/각도로 오프셋 위치에 생성 |
| **ID** | 새로운 순차 ID 자동 부여 |
| **타입** | 원본과 동일한 타입 유지 |

---

## 7.7 Undo / Redo (실행 취소 / 다시 실행)

모든 편집 작업은 실행 취소할 수 있습니다.

| 키 | 동작 |
|----|------|
| `Ctrl+Z` | 마지막 작업 실행 취소 (Undo) |
| `Ctrl+Y` | 취소한 작업 다시 실행 (Redo) |

Undo/Redo가 지원되는 작업:

- 어노테이션 생성/삭제
- 이동, 크기 조절, 회전
- 타입 변경
- 복사/붙여넣기
- 정렬 (Align Horizontal/Vertical, Make Perpendicular)

---

## 7.8 선택 해제

캔버스의 빈 공간을 클릭하면 선택이 해제됩니다.
