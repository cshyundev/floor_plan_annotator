# 3. 벽 어노테이션

벽(Wall) 도구는 평면도의 벽을 직선 세그먼트로 표시합니다. 여러 세그먼트를 이어서 연속 벽을 그릴 수 있습니다.

---

## 3.1 도구 활성화

- 키보드: `W`
- 도구 모음에서 벽 아이콘 클릭

도구가 활성화되면 커서가 십자선 모양으로 바뀝니다.

---

## 3.2 벽 그리기

### 기본 그리기 순서

![벽 그리기 순서 — 노드 1 클릭, 노드 2 클릭으로 세그먼트 생성](images/03_wall_draw_steps.png)

1. **첫 번째 클릭**: 벽의 시작점(노드)을 놓습니다.
2. **두 번째 클릭**: 끝점(노드)을 놓으면 두 노드 사이에 벽 세그먼트가 생성됩니다.
3. **계속 클릭**: 이전 끝점에서 이어지는 벽 세그먼트를 계속 추가합니다.

마우스를 이동하는 동안 다음 벽이 어디에 그려질지 미리보기 선이 표시됩니다.

### 그리기 종료

| 방법 | 동작 |
|------|------|
| **우클릭** | 현재 위치에서 그리기 종료 |
| **ESC** | 그리기 종료 후 선택 도구로 전환 |

---

## 3.3 기존 노드에 연결하기

새 벽을 기존 노드에서 시작하거나 끝낼 수 있습니다. 커서가 기존 노드 근처에 오면 자동으로 **노드 스냅**이 작동하여 정확히 연결됩니다.

![노드 스냅 — 커서가 기존 노드에 흡착되는 모습](images/03_node_snap.png)

스냅 범위 안에 들어오면 노드가 강조 표시됩니다. 이 상태에서 클릭하면 정확히 해당 노드에 연결됩니다.

---

## 3.4 스냅 가이드

벽을 그리는 동안 자동 정렬 가이드선이 표시됩니다.

![스냅 가이드 — 파란/초록/빨간 가이드선이 표시된 상태](images/03_snap_guides.png)

| 가이드 색상 | 의미 |
|------------|------|
| **파란색** | 수평(0°) 또는 수직(90°) 방향으로 스냅됨 |
| **초록색** | 기존 벽과 평행 또는 수직으로 스냅됨 |
| **빨간색** | 기존 어노테이션의 X 또는 Y 좌표와 정렬됨 |

`Shift` 키를 누르는 동안 스냅이 일시적으로 비활성화됩니다.

> **자세한 내용**: [8. 스냅 및 정렬](08_snap_align.md)을 참고하세요.

---

## 3.5 벽 선택 및 편집

`ESC`를 눌러 선택 도구로 전환한 후 벽을 편집합니다.

![벽 선택 상태 — 노드와 세그먼트가 강조된 모습](images/03_wall_selected.png)

### 노드 이동

벽의 끝점(노드)을 드래그하면 해당 노드의 위치를 조정할 수 있습니다. 연결된 모든 벽 세그먼트가 함께 변형됩니다.

### 삭제

선택한 벽 세그먼트 또는 노드를 `Delete` 또는 `Backspace`로 삭제합니다.

- **세그먼트 삭제**: 해당 세그먼트만 제거됩니다. 연결된 노드는 남아 있어 다른 세그먼트와 연결할 수 있습니다.
- **노드 삭제**: 노드에 연결된 모든 세그먼트가 함께 삭제됩니다.

---

## 3.6 벽 정렬 (컨텍스트 메뉴)

벽 세그먼트를 정확히 수평 또는 수직으로 맞추려면 우클릭 컨텍스트 메뉴를 사용합니다.

![벽 우클릭 컨텍스트 메뉴 — Align Horizontal, Align Vertical 항목](images/03_wall_context_menu.png)

| 항목 | 동작 |
|------|------|
| **Align Horizontal** | 두 노드의 Y 좌표를 평균값으로 맞춰 정확히 수평으로 정렬 |
| **Align Vertical** | 두 노드의 X 좌표를 평균값으로 맞춰 정확히 수직으로 정렬 |

두 항목 모두 Undo(`Ctrl+Z`)로 되돌릴 수 있습니다.

---

## 3.7 벽 호버 상태 표시

선택 도구로 벽 위에 마우스를 올리면 하단 상태바에 현재 벽의 정렬 상태가 표시됩니다.

| 상태바 메시지 | 의미 |
|--------------|------|
| `Wall: Horizontal (0.2° off)` | 거의 수평 (녹색 강조) |
| `Wall: Vertical (1.5° off)` | 거의 수직 (녹색 강조) |
| `Wall: 37.5° from nearest H/V` | 수평/수직에서 많이 벗어남 (주황 강조) |

![벽 호버 — 수평에 가까운 경우 녹색, 기울어진 경우 주황색으로 강조](images/03_wall_hover.png)

---

## 3.8 꼭짓점 직각 만들기 (Make Perpendicular)

두 개의 벽 세그먼트가 만나는 노드를 정확히 90°로 만들 수 있습니다.

1. 노드(꼭짓점) 위에서 **우클릭**
2. 컨텍스트 메뉴에서 **Make Perpendicular** 선택

![노드 우클릭 컨텍스트 메뉴 — Make Perpendicular 항목](images/03_node_context_menu.png)

> **조건**: 해당 노드에 정확히 2개의 벽 세그먼트가 연결되어 있어야 합니다.
