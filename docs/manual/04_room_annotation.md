# 4. 방 어노테이션

방(Room) 도구는 폐곡선 다각형으로 방의 영역을 정의합니다. 각 방에는 타입(거실, 침실 등)을 지정하며, 고유한 ID가 자동으로 부여됩니다.

---

## 4.1 도구 활성화

- 키보드: `R`
- 도구 모음에서 방 아이콘 클릭

도구가 활성화되면 커서가 십자선 모양으로 바뀝니다.

---

## 4.2 방 그리기

### 그리기 순서

![방 그리기 순서 — 꼭짓점을 하나씩 클릭하여 다각형을 완성하는 과정](images/04_room_draw_steps.png)

1. **첫 번째 클릭**: 다각형의 첫 번째 꼭짓점을 놓습니다. 첫 번째 노드는 다른 색으로 강조 표시됩니다.
2. **계속 클릭**: 꼭짓점을 하나씩 추가합니다. 마우스를 이동하면 다음 변이 미리보기로 표시됩니다.
3. **다각형 닫기**: 최소 3개의 꼭짓점을 추가한 후 아래 방법 중 하나로 닫습니다.
   - 첫 번째 노드 근처에서 클릭 (자동 스냅)
   - **우클릭**

### 다각형 닫기

![첫 번째 노드 근처 클릭으로 다각형 닫기 — 노드 강조 표시](images/04_room_close.png)

첫 번째 노드 근처에 커서가 오면 노드가 강조되고 "닫기" 스냅이 작동합니다. 이 상태에서 클릭하면 다각형이 완성됩니다.

---

## 4.3 타입 선택 팝업

다각형을 닫으면 즉시 타입 선택 팝업이 나타납니다.

![방 타입 선택 팝업 — Kitchen, Bedroom 등 목록](images/04_room_type_popup.png)

기본 제공 타입:

| 타입 | 설명 |
|------|------|
| Living Room | 거실 |
| Bedroom | 침실 |
| Master Room | 안방 |
| Kitchen | 주방 |
| Bathroom | 욕실 |
| Corridor | 복도 |
| Entrance | 현관 |
| Balcony | 발코니 |
| Utility | 유틸리티 룸 |

> **타입 추가/편집**: [9. 타입 관리](09_type_manager.md)를 참고하세요.

---

## 4.4 방 라벨

방이 생성되면 캔버스 중앙에 라벨이 표시됩니다.

```
Living Room (0)
```

라벨 형식: `[타입 이름] ([ID])`

ID는 같은 타입 내에서 자동으로 순서대로 부여됩니다 (0, 1, 2, ...).

![방 라벨이 다각형 중앙에 표시된 상태](images/04_room_label.png)

---

## 4.5 방 선택 및 편집

`ESC`를 눌러 선택 도구로 전환한 후 방을 편집합니다.

### 방 선택

방의 내부 영역을 클릭하면 선택됩니다. 선택된 방은 테두리가 강조 표시됩니다.

### 방 이동

방의 내부를 드래그하면 방 전체가 이동합니다. 방의 모든 꼭짓점이 함께 이동합니다.

![방 이동 — 내부 드래그로 전체 이동](images/04_room_move.png)

### 꼭짓점 이동

방을 선택한 후 꼭짓점(노드)을 드래그하면 해당 꼭짓점만 이동합니다. 방의 모양을 세밀하게 조정할 때 사용합니다.

![꼭짓점 이동 — 노드 드래그로 형태 조정](images/04_room_vertex_move.png)

### 방 회전

방을 선택하면 상단 중앙에 **회전 핸들**이 나타납니다. 핸들을 드래그하면 방 중심을 기준으로 회전합니다.

![방 회전 — 상단 핸들 드래그로 회전](images/04_room_rotate.png)

---

## 4.6 타입 변경

이미 생성된 방의 타입을 변경하려면:

1. 선택 도구(`ESC`)로 방을 클릭하여 선택
2. 방 위에서 **우클릭**
3. 컨텍스트 메뉴에서 원하는 타입 선택

![방 우클릭 컨텍스트 메뉴 — 타입 목록과 현재 타입 체크 표시](images/04_room_context_menu.png)

현재 선택된 타입에는 체크 표시가 됩니다.

---

## 4.7 방 삭제

선택한 방을 `Delete` 또는 `Backspace`로 삭제합니다. 방을 구성하는 꼭짓점과 변이 함께 삭제됩니다.

---

## 4.8 공유 노드

방의 꼭짓점은 벽이나 다른 방의 꼭짓점과 공유할 수 있습니다. 공유 노드를 이동하면 연결된 모든 어노테이션에 영향을 줍니다.
