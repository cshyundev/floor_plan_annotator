# 10. 파일 관리

어노테이션 작업 결과는 JSON 형식의 프로젝트 파일로 저장됩니다. 자동저장과 최근 파일 기능을 통해 작업 내용을 안전하게 관리할 수 있습니다.

---

## 10.1 프로젝트 파일 형식

어노테이션은 `annotations.json` 파일로 저장됩니다. 이 파일에는 다음 정보가 포함됩니다.

- 모든 벽, 방, 구역, 객체 어노테이션 데이터
- 좌표계 설정
- 3D 데이터 파일 참조 경로
- 생성 시각 및 수정 시각

프로젝트 파일은 3D 데이터 파일과 같은 폴더에 저장하는 것을 권장합니다.

---

## 10.2 저장

### 현재 파일에 저장

| 방법 | 동작 |
|------|------|
| `Ctrl+S` | 현재 파일 경로에 저장 |
| `File > Save Project` | 동일 |

처음 저장하는 경우(새 프로젝트) 파일 저장 다이얼로그가 나타납니다.

### 다른 이름으로 저장

| 방법 | 동작 |
|------|------|
| `Ctrl+Shift+S` | 새 경로/이름으로 저장 |
| `File > Save Project As` | 동일 |

![저장 다이얼로그 — annotations.json 기본 파일명으로 저장](images/10_save_dialog.png)

---

## 10.3 저장되지 않은 변경사항 표시

편집 작업 후 저장하지 않은 변경사항이 있을 때 타이틀바에 `*` 가 표시됩니다.

```
Floor Plan Annotator — /path/to/annotations.json *
```

`Ctrl+S`로 저장하면 `*` 가 사라집니다.

![타이틀바 — 저장되지 않은 상태의 * 표시](images/10_unsaved_indicator.png)

---

## 10.4 프로젝트 열기

### File > Recent Files

이전에 저장하거나 열었던 파일을 최대 5개까지 기억합니다.

1. `File > Recent Files` 선택
2. 목록에서 원하는 파일 선택

![File > Recent Files 메뉴 — 최근 파일 목록](images/10_recent_files_menu.png)

파일이 더 이상 존재하지 않으면 목록에서 자동으로 제거됩니다.

**목록 초기화**: `File > Recent Files > Clear Recent Files`

### 직접 열기

`Ctrl+S`로 저장된 파일을 직접 열려면, 해당 3D 데이터를 먼저 로드하세요. 같은 폴더에 `annotations.json`이 있으면 자동으로 감지됩니다.

---

## 10.5 자동저장

자동저장은 일정 시간마다 작업 내용을 자동으로 백업합니다.

### 자동저장 파일

자동저장 파일은 원본 파일과 같은 폴더에 숨김 파일로 저장됩니다.

```
annotations.json          ← 원본 (수동 저장)
.annotations.json.autosave.json  ← 자동저장 백업
```

### 자동저장 동작

- **조건**: 프로젝트 파일 경로가 설정된 경우에만 작동 (`Ctrl+S`로 한 번 이상 저장한 후)
- **간격**: 기본 5분 (Preferences에서 변경 가능)
- **내용**: 미저장 변경사항이 있을 때만 저장
- **수동 저장 시**: 자동저장 백업 파일이 삭제됨 (중복 불필요)

### 자동저장 설정

`Tools > Preferences`에서 설정합니다.

![Preferences 창 — Auto-save 설정 항목](images/10_preferences_autosave.png)

| 설정 | 설명 |
|------|------|
| Enable auto-save | 자동저장 활성화/비활성화 |
| Interval (minutes) | 저장 간격 (1~60분) |

> **자세한 내용**: [12. 환경설정 및 단축키](12_settings.md)를 참고하세요.

---

## 10.6 프로그램 종료 시 확인

저장되지 않은 변경사항이 있는 상태에서 종료하려 하면 확인 대화가 나타납니다.

![종료 확인 다이얼로그 — Save, Discard, Cancel 버튼](images/10_exit_confirm.png)

| 버튼 | 동작 |
|------|------|
| **Save** | 저장 후 종료 |
| **Discard** | 저장하지 않고 종료 |
| **Cancel** | 종료 취소, 작업 계속 |

|------|----------|
