# 5. 구역 어노테이션

구역(Zone) 도구는 청결 구역, 위험 구역 등 평면도 내의 특수 영역을 다각형으로 정의합니다. 그리기 방식은 방 도구와 동일하며, 다른 타입 목록을 사용합니다.

---

## 5.1 도구 활성화

- 키보드: `Z`
- 도구 모음에서 구역 아이콘 클릭

---

## 5.2 구역 그리기

그리기 방법은 [4. 방 어노테이션](04_room_annotation.md)과 완전히 동일합니다.

![구역 그리기 순서 — 꼭짓점 클릭으로 다각형 완성](images/05_zone_draw_steps.png)

1. 첫 번째 꼭짓점 클릭
2. 꼭짓점 추가 클릭 (최소 3개)
3. 첫 노드 근처 클릭 또는 **우클릭**으로 닫기
4. 타입 선택 팝업에서 구역 타입 선택

---

## 5.3 타입 선택 팝업

다각형을 닫으면 구역 타입 선택 팝업이 나타납니다.

![구역 타입 선택 팝업 — Clean Zone, Danger Zone 등 목록](images/05_zone_type_popup.png)

기본 제공 타입:

| 타입 | 설명 |
|------|------|
| Clean Zone | 청결을 유지해야 하는 구역 |
| Danger Zone | 접근 주의 또는 위험 구역 |
| Complex Zone | 복잡한 구조나 특수한 주의가 필요한 구역 |
| annotation | 일반 주석 구역 |

> **타입 추가/편집**: [9. 타입 관리](09_type_manager.md)를 참고하세요.

---

## 5.4 구역 라벨

구역이 생성되면 다각형 중앙에 라벨이 표시됩니다.

```
Clean Zone (0)
```

라벨 형식: `[타입 이름] ([ID])`

![구역 라벨이 다각형 중앙에 표시된 상태](images/05_zone_label.png)

---

## 5.5 구역 선택 및 편집

선택 도구(`ESC`)로 전환한 후 방 어노테이션과 동일한 방식으로 편집합니다.

| 조작 | 동작 |
|------|------|
| 구역 내부 클릭 | 구역 선택 |
| 구역 내부 드래그 | 구역 전체 이동 |
| 꼭짓점(노드) 드래그 | 해당 꼭짓점만 이동 |
| 회전 핸들 드래그 | 구역 회전 |
| 구역 위 우클릭 | 타입 변경 컨텍스트 메뉴 |
| `Delete` / `Backspace` | 구역 삭제 |

![구역 선택 상태 — 회전 핸들이 표시된 모습](images/05_zone_selected.png)

---

## 5.6 방과 구역의 차이

| 항목 | 방 (Room) | 구역 (Zone) |
|------|-----------|-------------|
| 단축키 | `R` | `Z` |
| 타입 목록 | 거실, 침실, 주방 등 건축적 구분 | 청결, 위험 등 기능적 구분 |
| 주요 용도 | 건축 평면도 구조 표시 | 로봇 내비게이션, 특수 영역 표시 |
| 그리기 방식 | 동일 | 동일 |

---

## 5.7 구역 활용 예시

- **청소 로봇**: Clean Zone에서 일반 청소, Danger Zone 진입 금지
- **안전 관리**: 위험 기계 주변을 Danger Zone으로 표시
- **물류 로봇**: 복잡한 교차 구역을 Complex Zone으로 표시하여 속도 제어
