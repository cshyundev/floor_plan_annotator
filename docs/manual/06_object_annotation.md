# 6. 객체 어노테이션

객체(Object) 도구는 가구, 가전제품, 장애물 등을 방향성 경계 박스(OBB, Oriented Bounding Box)로 표시합니다. 회전 각도를 포함한 직사각형 박스로 객체의 위치, 크기, 방향을 정확하게 표현합니다.

---

## 6.1 도구 활성화

- 키보드: `O`
- 도구 모음에서 객체 아이콘 클릭

---

## 6.2 객체 그리기

### 그리기 방법

![객체 그리기 — 클릭+드래그로 직사각형 영역 지정](images/06_object_draw.png)

1. 캔버스에서 **클릭+드래그**로 객체 영역을 지정합니다.
   - 클릭한 지점이 한쪽 모서리, 마우스 버튼을 놓는 지점이 대각 모서리가 됩니다.
   - 드래그하는 동안 점선 미리보기가 표시됩니다.
2. 마우스 버튼을 놓으면 **타입 선택 팝업**이 나타납니다.
3. 타입을 선택하면 객체가 생성됩니다.

### 점선 미리보기

![점선 미리보기 — 드래그 중 직사각형 크기 확인](images/06_object_preview.png)

드래그하는 동안 생성될 OBB의 크기를 점선으로 확인할 수 있습니다.

---

## 6.3 타입 선택 팝업

![객체 타입 선택 팝업 — Furniture, Appliance 등 목록](images/06_object_type_popup.png)

기본 제공 타입:

| 타입 | 설명 |
|------|------|
| Furniture | 가구 (소파, 침대, 책상 등) |
| Table | 테이블 |
| Appliance | 가전제품 (냉장고, 세탁기 등) |
| Obstacle | 기타 장애물 |

> **타입 추가/편집**: [9. 타입 관리](09_type_manager.md)를 참고하세요.

---

## 6.4 객체 선택

선택 도구(`ESC`)로 전환한 후 객체를 클릭하여 선택합니다. 선택된 객체에는 다음이 표시됩니다.

- 테두리 강조
- 4개의 모서리 핸들
- 상단 중앙의 회전 핸들

![객체 선택 상태 — 모서리 핸들과 회전 핸들이 표시된 모습](images/06_object_selected.png)

---

## 6.5 객체 편집

### 이동

객체의 중심 영역을 드래그하면 객체 전체가 이동합니다.

![객체 이동 — 중심 드래그](images/06_object_move.png)

### 크기 조절

객체의 4개 **모서리 핸들** 중 하나를 드래그합니다.

- 드래그하는 모서리가 이동합니다.
- 반대편 대각선 모서리는 고정됩니다.
- 객체의 회전 방향은 유지됩니다.

![객체 크기 조절 — 모서리 핸들 드래그 (대각 모서리 고정)](images/06_object_resize.png)

### 회전

객체 상단의 **회전 핸들**을 드래그합니다.

- 객체 중심을 기준으로 회전합니다.
- 0°, 90°, 180°, 270° 근방에서는 각도 스냅이 작동합니다.

![객체 회전 — 상단 핸들 드래그로 회전 (스냅 가이드 표시)](images/06_object_rotate.png)

---

## 6.6 타입 변경

이미 생성된 객체의 타입을 변경하려면:

1. 선택 도구로 객체를 클릭하여 선택
2. 객체 위에서 **우클릭**
3. 컨텍스트 메뉴에서 원하는 타입 선택

![객체 우클릭 컨텍스트 메뉴 — 타입 목록과 현재 타입 체크 표시](images/06_object_context_menu.png)

---

## 6.7 객체 3D 속성

객체는 3D 높이 정보를 가집니다. 이 정보는 3D 뷰어에서 OBB 박스로 표시됩니다.

| 속성 | 설명 | 기본값 |
|------|------|--------|
| **Elevation** | 바닥에서 객체 바닥면까지의 높이 | 타입별 기본값 |
| **3D Height** | 객체의 3D 높이 | 타입별 기본값 |

### 3D 속성 조절

객체를 선택한 상태에서:

| 조작 | 동작 |
|------|------|
| `Ctrl` + 마우스 휠 | 3D Height(높이) 조절 |
| `Ctrl+Shift` + 마우스 휠 | Elevation(바닥 높이) 조절 |

![객체 3D 속성 — 3D 뷰어에서 OBB 박스로 표시된 상태](images/06_object_3d.png)

> **자세한 내용**: [11. 3D 뷰어](11_3d_viewer.md)를 참고하세요.

---

## 6.8 객체 삭제

선택한 객체를 `Delete` 또는 `Backspace`로 삭제합니다.

---

## 6.9 OBB와 일반 직사각형의 차이

OBB(Oriented Bounding Box)는 회전 각도가 포함된 직사각형입니다. 일반 캐드 도구의 직사각형과 달리, 임의의 방향으로 기울어진 객체의 실제 방향을 정확하게 표현할 수 있습니다.

| 항목 | 일반 직사각형 | OBB |
|------|--------------|-----|
| 방향 | 항상 축 정렬 | 임의 각도 가능 |
| 저장 정보 | x, y, width, height | center_x, center_y, width, height, angle |
| 회전 표현 | 불가 | 가능 |
