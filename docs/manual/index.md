# Floor Plan Annotator 사용자 메뉴얼

Floor Plan Annotator는 3D 포인트 클라우드, 메시, 점유 그리드 데이터를 기반으로 2D 평면도를 작성하고 어노테이션하는 도구입니다. 이 메뉴얼은 처음 사용하는 어노테이터를 위한 안내서입니다.

## 빠른 시작

1. **데이터 로드**: `File > Load Point Cloud` 또는 `File > Load Occupancy Grid`
2. **벽 그리기**: `W` 키 → 캔버스 클릭으로 벽 추가
3. **방 그리기**: `R` 키 → 꼭짓점 클릭 → 닫기 → 타입 선택
4. **객체 그리기**: `O` 키 → 드래그로 영역 지정 → 타입 선택
5. **저장**: `Ctrl+S`

---

## 어노테이션 타입 개요

| 타입 | 단축키 | 설명 |
|------|--------|------|
| 벽 (Wall) | `W` | 직선 세그먼트로 구성되는 벽 |
| 방 (Room) | `R` | 폐곡선 다각형으로 정의하는 방 영역 |
| 구역 (Zone) | `Z` | 청결 구역, 위험 구역 등 특수 영역 |
| 객체 (Object) | `O` | 가구, 가전 등의 방향성 경계 박스 (OBB) |
