# REQ-023: 2D Slice Color Projection

- **Status**: Implemented
- **Description**: When projecting 3D points onto a 2D floor plan image, display each pixel using the color of the topmost point at that location instead of a binary white/black density map.

## Topmost Point Selection

- Use the coordinate system's `height_column()` and `up_direction` to determine which point is topmost.
- When multiple points map to the same pixel, the point with the highest effective height (`height_value * up_direction`) determines the pixel color.

## Color Dilation

- Apply color-aware dilation to maintain wall thickness, matching the existing binary dilation behavior.
- Dilated pixels use the color of the nearest source pixel.

## Occupancy Grid Mode

- This feature must NOT activate in occupancy grid mode.
- Occupancy grid mode continues to use its existing grayscale image display.

## Backward Compatibility

- When color data is not available, fall back to the existing grayscale projection.
