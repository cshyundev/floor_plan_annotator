# REQ-006: Room Annotation

- **Status**: Implemented
- **Description**: The system shall provide a tool to draw and annotate rooms on the 2D floor plan as polygons with customizable properties (name, type).

## Drawing Behavior
- Left-click to add polygon vertices one by one
- Clicking near the first vertex (within snap tolerance) closes the polygon and completes the room (minimum 3 vertices required)
- Right-click also closes the polygon as an alternative
- On completion, a room type selection popup appears

## Visual Styling (managed in `config/colors.yaml`)
- **Room polygon edge**: Blue (`room.edge.color: [0, 0, 255]`), distinct from wall edges (gray)
- **Room polygon edge width**: `room.edge.width: 2`
- **Room fill**: Semi-transparent solid fill using room type color (RGBA with alpha)
- **Snap tolerance**: `room.edge.snap_tolerance: 15` pixels to close polygon
- Temp edges during drawing use the same blue room edge color
- Completed RoomItem polygon uses the same blue room edge color from config

## Interaction After Completion
- When the Room Tool is active but no polygon is being drawn:
  - Clicking on an existing room's interior selects and allows moving the whole polygon
  - Clicking on a room's vertex node allows dragging it for detail adjustment
  - Clicking on empty space starts a new polygon
- When actively drawing a new polygon (vertices placed but not closed):
  - Left-click adds vertices as normal
  - Clicking near first vertex closes the polygon
- RoomItem handles drag (interior click) and rotation (handle) internally
- NodeItem with `ItemIsMovable` flag allows vertex adjustment by dragging

## Room Properties
- Each room has a unique sequential integer ID (0, 1, 2, 3, ...)
- IDs are assigned by a counter on Canvas2D (`_next_room_id`)
- When loading a project, the counter resets to `max(existing IDs) + 1`
- Room type selected from config/rooms.yaml (e.g., living_room, kitchen)
- Room types can be added/edited/deleted in the Room Types editor tab
- Label displays type name and ID at polygon centroid (e.g., "Living Room (2)")

## Selection & Editing
- Clicking a room's interior selects it (`setSelected(True)`) and enables drag
- Selected rooms can be deleted, copied, or have their type changed via context menu
- ESC switches to Select Tool and cleans up any in-progress drawing (temp nodes/edges removed)

## Delete
- **Toolbar button**: "Delete" button in toolbar deletes selected items
- **Keyboard shortcut**: Delete key also deletes selected items
- Deleting a RoomItem also removes its associated nodes and edges

## Copy & Paste
- **Ctrl+C**: Copies selected RoomItem(s) data to clipboard
- **Ctrl+V**: Pastes with 20px offset, assigns new sequential room ID
