# REQ-027: Recent Files

- **Status**: Proposed
- **Description**: The system shall maintain a list of recently opened project files and make them accessible from the File menu, persisted across application restarts.

## Behavior

- File menu contains a "Recent Files" submenu listing the last 5 opened/saved files
- Each entry shows the file's base name; full path shown in the status bar or tooltip on hover
- Clicking an entry opens that project (with unsaved-change confirmation per REQ-026)
- If the file no longer exists, it is silently removed from the list and a brief status bar message is shown
- A "Clear Recent Files" entry at the bottom of the submenu clears the entire list
- When the list is empty, the submenu shows a single disabled entry "(No recent files)"

## Persistence

- Stored via `QSettings` under the key `recentFiles` (list of absolute paths)
- Loaded on application startup
- Updated on every successful save or open

## Implementation Notes

- `_recent_files: list[str]` in `MainWindow`, max 5 entries (most recent first)
- Deduplication: if a path already exists in the list, move it to the front
- `_update_recent_files_menu()` rebuilds the submenu actions from the list
- `_add_to_recent_files(path: str)` — insert at front, trim to 5, persist to `QSettings`, rebuild menu
