# REQ-013: Custom Polygon Annotation

- **Status**: Implemented
- **Description**: The system shall provide a tool to draw user-defined polygon annotations on the 2D floor plan, supporting arbitrary polygon types (e.g., clean zone, danger zone) with configurable visual styling.

## Drawing Behavior
- Activated via toolbar button "Custom Polygon" or keyboard shortcut `P`
- Left-click to add polygon vertices one by one
- Clicking near the first vertex (within snap tolerance) closes the polygon (minimum 3 vertices)
- Right-click also closes the polygon
- On completion, a type selection popup appears listing available custom polygon types from `config/custom_polygons.yaml`

## Visual Styling
- Each custom polygon type defines its own fill color (RGBA) and border color (RGB) in `config/custom_polygons.yaml`
- Border width: `ui_config.yaml → custom_polygon.width` (default 0.02m)
- Z-value: `ui_config.yaml → custom_polygon.z_value` (default 42, above rooms, below objects)
- Fallback colors used when type config is missing: `colors.yaml → fallback.custom_polygon`
- Label displays type name and ID at polygon centroid (e.g., "Clean Zone (1)")

## Interaction
- Drag to move entire polygon (all nodes move together)
- Rotation handle at centroid offset allows rotating the polygon
- Individual vertex nodes are draggable for shape adjustment
- Right-click context menu allows changing the polygon type
- Type change is undoable via `ChangeCustomPolygonTypeCommand`

## Properties
- Each custom polygon has a unique sequential integer ID (`_next_custom_polygon_id` counter on Canvas2D)
- Polygon type key (e.g., `clean_zone`, `danger_zone`)
- List of vertex nodes (shared with other polygons/walls if overlapping)

## Data Model
- `CustomPolygon` in `src/model/data.py`: `polygon_type`, `polygon_id`, list of `Point2D` vertices
- Serialized/deserialized via `ProjectData` JSON format
