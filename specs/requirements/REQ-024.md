# REQ-024: Shared Nodes Between Annotations

- **Status**: Implemented
- **Description**: When drawing polygon-based annotations (room, custom polygon), clicking on an existing NodeItem reuses that node instead of creating a new one. This allows different annotation types (wall, room, custom polygon) to share nodes. Moving a shared node updates all connected annotations. Deleting an annotation preserves shared nodes that are still referenced by other annotations. ObjectItem is excluded (uses OBB, no NodeItem).
