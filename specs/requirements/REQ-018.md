# REQ-018: Type Management System

- **Status**: Implemented
- **Description**: The system shall provide runtime management of annotation types (room types, custom polygon types, object types) through dock editor widgets, with changes persisted to YAML config files.

## Supported Type Categories
- **Room Types** (`config/rooms.yaml`): e.g., living_room, kitchen, bedroom
- **Custom Polygon Types** (`config/custom_polygons.yaml`): e.g., clean_zone, danger_zone
- **Object Types** (`config/objects.yaml`): e.g., furniture, appliance

## Type Definition
Each type has:
- `key`: Unique identifier string (e.g., `living_room`)
- `name`: Display name (e.g., "Living Room")
- `color`: Fill color as RGBA list (e.g., `[100, 200, 150, 80]`)
- `border`: Border color as RGB list (e.g., `[50, 150, 100]`)
- `index`: Sort order for display in popups and editors

## Dock Editor Widgets
- Three separate tabs in the right dock panel: "Room Types", "Custom Polygon Types", "Object Types"
- Each editor provides:
  - **List** of existing types with color preview
  - **Add**: Create a new type with name, key, fill color, and border color
  - **Edit**: Modify name and colors of existing types via color picker dialog
  - **Delete**: Remove a type (existing annotations of deleted types retain their data but use fallback colors)

## Type Selection Popups
- Appear after completing an annotation drawing (room, custom polygon, or object)
- List available types sorted by index
- Clicking a type assigns it to the newly created annotation

## Live Update
- Editing a type's color in the dock editor emits `config_changed` signal
- Canvas responds by calling `update_all_rooms()`, `update_all_custom_polygons()`, or `update_all_objects()`
- Each annotation item's `update_style()` re-reads its type config and applies new colors immediately
- No app restart required for type color changes

## Persistence
- Changes are saved immediately to the corresponding YAML file via `ConfigManager.save_config()`
- Config files are read at startup via `ConfigManager.load_configs()`
