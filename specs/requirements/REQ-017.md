# REQ-017: 3D Annotation Sync

- **Status**: Implemented
- **Description**: The system shall synchronize 2D annotation changes to the 3D viewer in real-time, generating 3D geometry for rooms, walls, custom polygons, and objects.

## Synchronized Annotation Types
- **Rooms**: Rendered as horizontal floor planes at `annotation_3d.floor_z_level`
- **Walls**: Rendered as vertical planes with height `annotation_3d.wall_height`
- **Custom Polygons**: Rendered as horizontal planes (same as rooms)
- **Objects**: Rendered as 3D boxes with height `annotation_3d.object_height`

## Sync Triggers
- Creating, moving, resizing, rotating, or deleting an annotation item triggers 3D geometry update
- Type changes (e.g., room type change) trigger geometry color update
- Undo/redo operations trigger corresponding 3D geometry updates

## Configuration (`config/ui_config.yaml → annotation_3d`)
- `wall_height`: Height of virtual wall planes (default 1.5m)
- `floor_z_level`: Z level for room/polygon floor planes (default 0.0)
- `object_height`: Height of object bounding boxes (default 0.5m)
- `enable_room_planes`: Toggle room plane visibility
- `enable_wall_geometry`: Toggle wall geometry visibility
- `enable_custom_polygon_planes`: Toggle custom polygon plane visibility
- `enable_object_boxes`: Toggle object box visibility

## Geometry Visibility
- "Show Original 3D Data" checkbox in View Controls tab toggles point cloud visibility
- Individual annotation type visibility controlled by `annotation_3d.enable_*` config flags
- Slice height 변경 시 "Show Original 3D Data" 체크박스가 꺼져있으면 자동으로 다시 활성화하여 크롭된 geometry를 표시
- 체크박스 상태가 UI에 즉시 반영되어 사용자에게 가시성 변경을 명확히 전달

## Graceful Degradation
- If Open3D is not available, `Viewer3DStub` is used instead — shows placeholder message, all sync calls are no-ops
- 3D viewer failure does not affect 2D canvas functionality
