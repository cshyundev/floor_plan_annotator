# REQ-005: Wall Annotation

- **Status**: Implemented
- **Description**: The system shall provide a tool to draw and annotate walls on the 2D floor plan as line segments with configurable thickness.

## Deletion Behavior

- **NodeItem 삭제 시**: 연결된 모든 EdgeItem도 함께 삭제된다.
- **EdgeItem 삭제 시**: 연결이 끊긴 고아 NodeItem은 유지된다 (사용자가 새 edge를 연결할 수 있도록).
