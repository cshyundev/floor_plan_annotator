# REQ-015: Clipboard Operations

- **Status**: Implemented
- **Description**: The system shall support copy and paste of annotation items across all annotation types, with offset pasting and automatic ID assignment.

## Supported Types
- RoomItem (polygon with nodes)
- CustomPolygonItem (polygon with nodes)
- ObjectItem (standalone OBB)

## Copy (Ctrl+C)
- Copies all currently selected annotation items to an internal clipboard
- For polygon-based items (Room, CustomPolygon): serializes vertex positions, type, and ID
- For ObjectItem: serializes center, width, height, angle, type, and ID
- Wall edges (EdgeItem) are not independently copyable

## Paste (Ctrl+V)
- Pastes copied items with a pixel offset (`room.paste_offset` in `ui_config.yaml`, default 20px)
- Each pasted item receives a new sequential ID from the appropriate counter
- Pasted polygon items create new NodeItem vertices (not shared with originals)
- Paste is undoable as a single undo command

## Implementation
- Managed by `ClipboardManager` (delegated from `Canvas2D`)
- Clipboard data is stored in-memory (not system clipboard)
