# REQ-028: Project JSON Schema v4.0

- **Status**: Proposed
- **Description**: The system shall upgrade the project file format to version 4.0, adding project-level metadata fields and removing the absolute image path from the saved JSON to improve portability.

## New Fields

| Field | Type | Description |
|-------|------|-------------|
| `project_name` | string | Human-readable project name. Defaults to the file base name (without extension) on first save. |
| `created_at` | string (ISO 8601) | Timestamp of the first save. Set once and never overwritten on subsequent saves. |
| `modified_at` | string (ISO 8601) | Timestamp of the most recent save. Updated on every save. |

## Removed Fields

- `map_metadata.image_path_absolute` — **removed from the saved JSON**
  - The absolute path is still resolved at load time (from the relative path + project directory) and held in memory as `MapMetadata.image_path_absolute`, but it is never written to disk.
  - This prevents stale absolute paths from accumulating in committed project files.

## Schema

```json
{
  "version": "4.0",
  "project_name": "1F Lobby",
  "created_at": "2026-02-28T12:00:00",
  "modified_at": "2026-02-28T15:30:00",
  "coordinate_system": { ... },
  "map_metadata": {
    "image_path": "relative/map.png",
    "resolution": 0.05,
    "origin_x": -5.0,
    "origin_y": -3.0,
    "origin_yaw": 0.0,
    "negate": 0,
    "occupied_thresh": 0.65,
    "free_thresh": 0.196,
    "image_width": 200,
    "image_height": 150
  },
  "walls": [...],
  "rooms": [...],
  "objects": [...],
  "custom_polygons": [...]
}
```

## Backward Compatibility

- Files with version 1.0, 2.0, or 3.0 load normally; missing fields use defaults
- `image_path_absolute` found in old files is read into memory only (not re-saved unless schema is explicitly downgraded)
- On first save of a legacy file, it is upgraded to v4.0 automatically

## Implementation Notes

- `ProjectData.project_name: str = ""`
- `ProjectData.created_at: Optional[str] = None`
- `ProjectData.modified_at: Optional[str] = None`
- `ProjectIO.save_project()`: sets `modified_at` to current UTC time; sets `created_at` only if None
- `MapMetadata.to_dict()`: omits `image_path_absolute` key
- `MapMetadata.from_dict()`: reads `image_path_absolute` if present (for legacy files), stores in object field only
