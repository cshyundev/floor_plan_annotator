# REQ-022: Coordinate System Configuration

- **Status**: Implemented
- **Description**: Support multiple coordinate system conventions (ROS, OpenCV, OpenGL) for 3D data, with configurable floor level offset. Annotations are stored in the original data's coordinate system so that external systems (e.g., robots) can use them directly. The project file includes coordinate system metadata specifying which original axes correspond to Point2D.x, Point2D.y, and the vertical (height) axis.
