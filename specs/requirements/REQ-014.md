# REQ-014: Object Annotation (Oriented Bounding Box)

- **Status**: Implemented
- **Description**: The system shall provide a tool to annotate objects on the 2D floor plan as oriented bounding boxes (OBB) defined by center position, width, height, and rotation angle.

## Drawing Behavior
- Activated via toolbar button "Object" or keyboard shortcut `O`
- Click-and-drag to define the bounding box: press sets one corner, release sets the opposite corner
- A dashed preview rectangle is shown during drag
- On release, a type selection popup appears listing available object types from `config/objects.yaml`
- Clicking on an existing ObjectItem while in Object tool mode passes through to the item for direct manipulation

## Visual Styling
- Each object type defines fill color (RGBA) and border color (RGB) in `config/objects.yaml`
- Border width: `ui_config.yaml → object.width` (default 0.02m)
- Z-value: `ui_config.yaml → object.z_value` (default 45, above rooms and custom polygons)
- Orientation arrow (red) always drawn along the local X-axis direction
- When selected or hovered: corner handles (4 corners) and rotation handle (above top-center) are displayed
- Rotation handle is connected to center via a dashed line
- Label displays type name and ID at center (e.g., "Table (3)")
- Fallback colors: `colors.yaml → fallback.object`

## Interaction
- **Drag**: Click on body to move the entire OBB (center repositioned)
- **Resize**: Click-and-drag a corner handle to resize; opposite corner stays fixed
- **Rotate**: Click-and-drag the rotation handle to rotate around center
- All three transforms use a single undo command (`TransformObjectCommand`) that captures before/after state of center, width, height, and angle
- Right-click context menu allows changing the object type (`ChangeObjectTypeCommand`)
- Drawing tools are blocked from OBB interaction; only SelectTool and ObjectTool (in passthrough mode) allow item events

## Properties
- Unique sequential integer ID (`_next_object_id` counter on Canvas2D)
- Object type key (e.g., `furniture`, `appliance`)
- Center (`QPointF`), width (float, meters), height (float, meters), angle (float, degrees)

## Data Model
- `Object` in `src/model/data.py`: `object_type`, `object_id`, `center` (Point2D), `width`, `height`, `angle`
- Serialized/deserialized via `ProjectData` JSON format
