# REQ-016: Theming System

- **Status**: Implemented
- **Description**: The system shall support a centralized theming system where all visual styling is controlled through configuration files, enabling theme switching without code changes.

## Architecture
- Two-layer system:
  1. **QSS stylesheets** (`config/theme.qss`): Controls Qt widget appearance (toolbar, dock, buttons, menus, tabs, scrollbars, etc.)
  2. **Color config** (`config/colors.yaml`): Controls annotation item colors (nodes, walls, rooms, handles, axes, labels, etc.)
- `apply_theme(app)` called at application startup loads the QSS file and applies it to `QApplication`

## Color Configuration (`config/colors.yaml`)
- All annotation colors are centralized: nodes, walls, room edges, handles, labels, axes, fallbacks, tool previews
- Colors specified as RGB `[r, g, b]`, RGBA `[r, g, b, a]`, CSS string `"rgba(...)"`, or named color `"yellow"`
- Accessed via `ConfigManager.get_color(*keys)` which returns `QColor`
- Fallback to magenta `#FF00FF` if a color key is missing (makes misconfiguration visually obvious)

## Widget Styling (`config/theme.qss`)
- Standard Qt Style Sheet format
- Covers: QMainWindow, QMenuBar, QMenu, QToolBar, QToolButton, QDockWidget, QTabWidget, QTabBar, QPushButton, QLabel, QCheckBox, QComboBox, QSlider, QSplitter, QScrollBar, QLineEdit, QSpinBox, QGroupBox, QStatusBar, QToolTip, QTreeView, QListView

## Default Theme: Dark (Foxglove/Omniverse style)
- Surface hierarchy: `#12141A` (darkest/canvas) → `#1A1D26` (window) → `#22262F` (panel) → `#2A2E38` (header) → `#323844` (hover) → `#3A4050` (active)
- Primary text: `#E0E4EC`, Secondary: `#8890A0`, Disabled: `#505868`
- Accent: `#4FC3F7` (blue-cyan) — used for selections, active tabs, slider handles, focus borders
- Borders: `#2E3340` (subtle), `#3A4050` (strong)
- Canvas background set via `setBackgroundBrush()` from `colors.yaml → canvas.background`

## Size/Layout Configuration (`config/ui_config.yaml`)
- Non-color UI values: pen widths, radii, z-values, snap tolerances, handle sizes, window dimensions
- Accessed via `ConfigManager.get_ui_value(*keys)`

## Theme Switching
- To create a new theme: provide alternate `theme.qss` and `colors.yaml` files
- `apply_theme(app, theme_path)` accepts a custom QSS path
- Annotation item colors update automatically when `update_style()` is called (reads from `ConfigManager`)
