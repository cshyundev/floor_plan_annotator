# REQ-021: Occupancy Grid Annotation

- **Status**: Proposed (Draft)
- **Description**: The system shall support annotation on occupancy grids and export annotated regions as occupancy grid images.

## Input

- Load existing occupancy grid images (.pgm, etc.) for annotation.
- Generate occupancy grid from 3D point cloud data.

## Annotation

- Use existing polygon tools (Wall, Room, Custom Polygon) to define regions on the occupancy grid.
- On export, rasterize polygon annotations to produce an occupancy grid image.

## Layout

- To be determined: reuse existing dual-view layout or provide a separate mode/tab.

## Output

- Occupancy grid image (.pgm, etc.)
- Associated metadata file (.yaml)
