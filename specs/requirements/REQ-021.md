# REQ-021: Occupancy Grid Annotation

- **Status**: Accepted
- **Description**: The system shall load ROS2 map_server compatible occupancy grid maps (YAML metadata + image), display them as 2D background and 3D block mesh, and support annotation using existing tools.

## Input

- Load ROS2 map_server format: YAML metadata file (.yaml/.yml) referencing an image file (.pgm/.png).
- YAML fields: `image`, `resolution`, `origin` ([x, y, yaw]), `negate`, `occupied_thresh`, `free_thresh`.
- Support two loading paths:
  - Select a YAML file: auto-parse metadata and load referenced image.
  - Select an image file: auto-detect YAML in same directory; if not found, show manual metadata input dialog.

## 2D Display

- Display the occupancy grid image as the 2D canvas background using existing `update_background()`.
- Image orientation: no flip required (ROS image row 0 = world max_y matches canvas convention).
- Canvas bounds computed from map metadata: origin + image dimensions * resolution.

## 3D Display

- Generate a floor mesh (flat quad at z=0) covering the map extent.
- Generate block meshes for each occupied cell: `resolution x resolution x block_height` boxes.
- Display via `Viewer3D.set_geometry()` (new method accepting pre-created Open3D mesh).
- Height slider disabled (no slicing for occupancy grid mode).
- "Show Original 3D Data" checkbox remains active for mesh visibility toggle.

## Annotation

- Use existing annotation tools (Wall, Room, Custom Polygon, Object) without modification.
- Annotations stored in world coordinates (meters) as with point cloud mode.
- AnnotationSync3D disabled in occupancy grid mode (no 3D annotation geometry).

## UI

- File menu: "Load Occupancy Grid..." action.
- Map Info collapsible section in control dock: filename, resolution, origin, size, block height.
- Confirmation dialog when loading a new map with existing annotations.

## Project Save/Load

- Project file version bumped to 3.0.
- `MapMetadata` stored in project JSON (image path relative to project file + absolute fallback).
- On project load: resolve image path (relative → absolute → user file dialog fallback).
- Backward compatible: v2.0 projects load with `map_metadata = null`.

## Out of Scope (v1)

- Export/rasterization of annotations to occupancy grid images.
- Grid-cell snapping for polygon vertices.
- Origin yaw rotation (stored but not applied).
