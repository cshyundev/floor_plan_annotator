# REQ-004: 2D Projection

- **Status**: Implemented
- **Description**: The system shall project sliced 3D points onto a 2D plane to generate a floor plan image with configurable pixel resolution.

## Fixed Canvas Bounds

- 2D 캔버스의 크기와 위치는 전체 포인트 클라우드의 X,Y 범위를 기준으로 고정된다.
- 슬라이스 높이가 변경되어도 이미지 크기(픽셀 그리드)와 world bounds는 변하지 않는다.
- 슬라이스 변경 시 사용자의 줌/패 상태가 유지된다. (첫 로드 시에만 fitInView 호출)
