# REQ-020: Snap & Alignment Guide System

- **Status**: Implemented
- **Description**: All line-drawing tools and item drag operations shall provide visual guidelines and automatic/assisted correction for precise annotation placement.

## Features

### A. Global Angle Snapping
- While drawing a line segment, if the angle is within a configurable threshold of any angle in the global angle set (default: 0°/90°/180°/270°), display a visual guideline and automatically snap the endpoint.
- The angle threshold and angle set shall be configurable via `config/ui_config.yaml` (`snap.angle_threshold`, `snap.angle_set`).

### B. Relative Angle Snapping (Parallel/Perpendicular)
- While drawing a line segment, if it is nearly parallel or perpendicular to any existing edge in the scene, display a visual guideline and automatically snap.
- Relative offsets are configurable (`snap.relative_offsets`, default: `[0, 90]` for parallel/perpendicular).
- Extensible: other offsets (e.g. 45°) can be added via config.

### C. Cross-Object Alignment Guides
- When placing a new node or dragging an existing node/object/polygon, display alignment guide lines when the cursor's X or Y coordinate matches any existing annotation's position.
- Tolerance is in screen pixels, configurable (`snap.alignment_tolerance`).
- Drawing tools: alignment snap auto-corrects the position.
- Drag operations: guide-only display (Phase 1); auto-correction deferred to future enhancement.

### D. Shift Toggle
- Holding Shift temporarily toggles snap on/off (XOR with `snap.enabled` config).

## Guideline Visual Style
- Three distinct colors for orthogonal/relative/alignment guides, configurable in `config/colors.yaml` (`snap.*`).
- Cosmetic pen (1px on screen regardless of zoom).
- Dashed line style.
- Z-value: 200 (above all annotations).

### E. EdgeItem Hover — H/V Status Display
- While hovering over a wall (EdgeItem), display whether it is globally horizontal, vertical, or neither.
- Visual feedback: pen color changes to green (H/V aligned) or amber (non-aligned).
- Status bar message: "Wall: Horizontal (0.2° off)" / "Wall: 37.5° from nearest H/V".
- H/V detection threshold configurable via `config/ui_config.yaml` (`wall.hover.angle_threshold`).
- Hover pen width configurable via `config/ui_config.yaml` (`wall.hover.width`).
- Hover colors configurable via `config/colors.yaml` (`wall.hover.hv_color`, `wall.hover.other_color`).

### F. EdgeItem Context Menu — Align to H/V
- Right-click on a wall (EdgeItem) shows "Align Horizontal" / "Align Vertical" actions.
- Aligns the wall by averaging both node Y (horizontal) or X (vertical) coordinates.
- Disabled if alignment would not change positions (already exactly aligned).
- Supports Undo via `MoveNodesCommand`.

### G. NodeItem Context Menu — Make Perpendicular
- Right-click on a node connected to exactly 2 edges shows "Make Perpendicular" action.
- Moves the node to the nearest point on the Thales circle (diameter = segment between the two neighbor nodes), ensuring the angle at the node is exactly 90°.
- Preserves edge directions (closest point projection).
- Disabled if already exactly perpendicular (dot product ≈ 0).
- Supports Undo via `MoveNodeCommand`.

### H. First-Click Alignment Snap
- When placing the first node in wall drawing mode, alignment snap is applied so the node aligns with existing annotations' X/Y coordinates.

## Scope
- **Drawing tools**: Wall tool (REQ-005), Room tool (REQ-006), Custom Polygon tool (REQ-013), Object tool (REQ-015).
- **Drag operations**: NodeItem, ObjectItem, PolygonItem (RoomItem, CustomPolygonItem).
- **Post-hoc correction**: EdgeItem context menu (Align H/V), NodeItem context menu (Make Perpendicular).

## Configuration
- `config/ui_config.yaml`: `snap.enabled`, `snap.angle_threshold`, `snap.alignment_tolerance`, `snap.angle_set`, `snap.relative_snap`, `snap.relative_offsets`, `snap.guide_z_value`
- `config/ui_config.yaml`: `wall.hover.width`, `wall.hover.angle_threshold`
- `config/colors.yaml`: `snap.orthogonal_color`, `snap.relative_color`, `snap.alignment_color`
- `config/colors.yaml`: `wall.hover.hv_color`, `wall.hover.other_color`
