# REQ-020: Line Orthogonal Snapping

- **Status**: Proposed
- **Description**: All line-drawing tools (Wall, Room, Custom Polygon) shall provide visual guidelines and automatic correction when a line segment is near vertical or horizontal orientation.

## Behavior

- While drawing a line segment, if the angle is within a configurable threshold of vertical (90°) or horizontal (0°/180°), display a visual guideline indicating the snapped direction.
- When the angle is within the threshold, automatically snap the endpoint to produce an exactly vertical or horizontal line.
- The angle threshold shall be configurable.
- Guideline visual style (color, dash pattern, etc.) shall be configurable via config.

## Scope

- Applies to all tools that draw line segments: Wall tool (REQ-005), Room tool (REQ-006), Custom Polygon tool (REQ-013).
